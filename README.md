# 🏡 StayNest

### A Modern Full Stack Airbnb Clone

StayNest is a modern full-stack web application inspired by Airbnb, developed to provide users with a seamless and interactive property rental experience. The platform allows users to explore unique stays, manage property listings, and experience a clean, responsive, and user-friendly interface.

This project is built using **Node.js, Express.js, MongoDB, EJS, and Bootstrap**, following the **MVC Architecture** for better scalability and maintainability. It demonstrates real-world full-stack development concepts including authentication, RESTful routing, CRUD operations, database integration, middleware handling, image uploads, and responsive UI design.

StayNest provides secure user authentication and authorization, allowing users to create accounts, log in securely, and access protected functionalities. Users can create new property listings, upload images, edit listing details, and manage accommodations efficiently.

The application integrates **Cloudinary** for secure image hosting and storage, while **MongoDB** is used for handling database operations and data persistence. The project focuses on building a smooth user experience with optimized backend architecture and modern frontend design.
